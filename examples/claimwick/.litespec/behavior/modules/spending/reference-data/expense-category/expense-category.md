# Expense Category

Claimwick files each expense under one category, so finance sorts payouts by kind of cost. The table holds the four kinds with what each means, and the submission carries one of them.

## Values

The table holds four rows, one per kind: travel, meals, lodging and other, each in force from 2026-01-01 and resting on `decision/0006-expense-categories`. Travel is a trip to a client, meals is food on a work day, lodging is a night away, and other is a cost of no other kind. A new kind arrives as a new choice with its meaning and its row.

## Example

Ava files a trip to a client as travel: the submission carries the travel category from this table, and the expense keeps it.
