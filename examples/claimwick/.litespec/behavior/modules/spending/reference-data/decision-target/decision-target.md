# Decision Target

Claimwick decides each expense within the decision target in force when it was submitted. The table holds that target with the date it takes effect, so the approval rules cite one value instead of stating their own.

## Values

The table holds two rows, both playing the standard role: 5 business days from 2026-01-01 to 2026-12-31, then 3 business days from 2027-01-01, each resting on `research/approval-time-benchmarks`. A new row takes effect on its date, and the old row carries its end date.

## Example

An expense submitted on Monday is decided by the next Monday: the approval rule reads the target in force from this table.
