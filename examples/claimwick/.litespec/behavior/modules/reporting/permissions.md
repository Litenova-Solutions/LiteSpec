# Permissions

This permission set names what each person may do in the reporting module, with one permission for each allowed action. It concerns finance, which lists the reimbursed expenses. It matters because the list shows the employee each expense was paid to.

## Risk

`permission/list-reimbursed-expenses` is tagged personal data, because each row names the employee who was paid.

## Boundaries

- The list-reimbursed-expenses permission does not grant the right to reimburse an expense.
- The list-reimbursed-expenses permission changes none of the expenses it lists.
