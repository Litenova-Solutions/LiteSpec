# Accepted Agencies

Claimwick accepts travel bookings only from agencies it names per country. The table holds those agencies with the date the product starts accepting each one's bookings, so the expense form offers one list per country instead of trusting any booking source.

## Values

The table holds no rows yet: no country has stated the agencies it accepts. Each row will carry one agency name as its `value` with its `key`, the `variant` naming its country, the `effectiveFrom` date the product starts accepting its bookings, and the `source` behind the acceptance. The Germany and Netherlands sets build their `AcceptedAgency` rows from this table through the `knowledge-sets` target once rows are stated.
