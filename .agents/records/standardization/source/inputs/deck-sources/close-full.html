Recommendations for the Seams

The two layers are well separated on paper. Where they meet, the same rule is stated on several pages, the checks follow a narrower link set than the Links table, and a few promised mechanisms are not built.

1. Write the direction rule honestly

"Records never point down" and "nothing is computed from code" each have real exceptions: decides, holds, transcription. Name them as the only exceptions. Findings 1, 2.

2. One Links table drives everything

Complete the Links table, then generate the checker's link-target table, the book's labels and the parent lists from it. Findings 5, 6, 7.

3. Build or drop parent-changed

The top-down change story depends on a flag nothing emits. It is the mechanism that keeps Behavior honest when Intent moves. Finding 3.

4. One home per provision

Draft questions, world facts, layer derivation, proof statuses and the docs layout each live on two to four pages. Keep the provision in its home and cite it. Findings 4, 17.

5. One meaning per word

Tier, semantic hash, parent and founder each carry two or three meanings across the pages. Findings 13, 14, 18, 22.

6. Settle the open lifecycle

Question status, veto, coverage by known gaps and deviations, and auto-approval for records versus questions. Findings 8, 10, 15.
