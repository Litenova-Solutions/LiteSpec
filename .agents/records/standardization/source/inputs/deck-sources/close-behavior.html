Remaining Recommendations for the Behavior Layer

One medium finding and two lows remain open. Each is one small change with its evidence in the appendix.

1. Admit implementation to the term layer

The page allows implementation for code-only words; the glossary schema forbids it. Add it to the enum, or say which layer a read model takes. Finding 1.

2. Let a behavior term be reviewed

The schema allows every term only draft, approved or retired, while Behavior terms should carry the reviewed vocabulary. Make status conditional on layer. Finding 2.

3. Document manage or remove it

manage is a command verb in code and an access example, but never appears on the verb tables. Name it as a permission word, or remove it. Finding 3.
