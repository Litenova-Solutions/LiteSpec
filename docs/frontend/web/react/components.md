# React Components

**Stack:** react

**Concern:** frontend-ui

## Intent

A React component is a function using hooks, with props and events typed under strict mode. React states no component rule of its own: function components follow [Your First Component](https://react.dev/learn/your-first-component) in the React documentation, typed component boundaries follow [TypeScript Web Components](../components.md), and the shared component principles live in [Frontend Components](../../components.md). A team that applies those pages while writing components keeps every boundary compile-checked, so a wrong call fails at build time instead of in the browser.
