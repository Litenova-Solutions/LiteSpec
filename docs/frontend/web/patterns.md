# Web UI Patterns

**Stack:** react, svelte
**Concern:** frontend-ui

React and Svelte frontends implement a chosen UI pattern from shared rules. When you pick a pattern for a web screen, its implementation rules live in [Web UI](ui.md), which states the pattern implementation for the [React Stack](react/stack.md) and the [Svelte Stack](svelte/stack.md) together with the other shared UI rules.
