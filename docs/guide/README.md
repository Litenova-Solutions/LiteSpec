# Overview

## Intent

The Guides section teaches by doing: tutorials take a reader to a first working result one step at a time, and how-to guides solve one stated problem in a project that already runs. Every guide cites the standard it applies and adds no rule of its own, so a reader learns the standard by following along.

## Where to start

When LiteSpec is new, follow [Start a Consumer Repository](../tutorial/getting-started.md) first: it builds a working consumer with one implemented use case. Then follow [Model a Domain Module](../tutorial/model-domain.md) to model one business area the model builder reads. When the project runs and one goal needs solving, read the how-to that names it: [Build an Audit Trail](audit-trail.md) implements the audit extension on the .NET command pipeline, and [Check .NET Code with the Analyzers](../analyzers/check-dotnet-code-with-the-analyzers.md) runs the Roslyn analyzers over a .NET backend.
