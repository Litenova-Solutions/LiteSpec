# Overview

## Intent

The Core pages state what every LiteSpec project shares: the business area it covers, the size, shape, and technology stacks it selects, the records that hold its intent, the checks that join those records to code, and the rules for agents, writing, and releases. Read them once when starting a project, then load only the pages each task touches.

## How the pages fit together

Start with [LiteSpec](system.md) for the system the other pages detail, then [Supported Scope](scope.md) for the size, shape, and stacks a project selects. [Product Intent](product.md) and [Project Model](model.md) state what a project writes down, and [Agent Operating Protocol](agent.md) states how agents work from those records. [Authoring Standard](authoring.md) and [Maintaining the Standards](maintaining.md) state how pages themselves are written and kept, [Technology Stacks](stacks.md) states what a stack selection applies, [Engineering Principles](principles.md) settles choices no narrower page covers, and [Product Release](release.md) states what a release ships.

## System and scope

- [LiteSpec](system.md): what LiteSpec coordinates and the parts it combines.
- [Supported Scope](scope.md): the one size, one shape, and stacks each project selects.
- [Technology Stacks](stacks.md): what selecting a stack applies, and what each stack folder holds.
- [Engineering Principles](principles.md): the rules of thumb for choices no narrower rule covers.

## Intent and the model

- [Product Intent](product.md): where a consumer states its business intent and in what form.
- [Project Model](model.md): the record types, their links, and what the builder computes.

## Agents, authoring, and releases

- [Agent Operating Protocol](agent.md): how agents select context, resolve standards, and report completion.
- [Authoring Standard](authoring.md): page styles, provision contracts, identifiers, and prose style; what `litespec validate` checks.
- [Maintaining the Standards](maintaining.md): the maintainer manual for provision lifecycle, renames, citations, and releases.
- [Product Release](release.md): what a release joins to its evidence, and what a maintainer operates.
