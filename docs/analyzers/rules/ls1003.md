# LS1003: Aggregate Has No State Record

LS1003 reports an aggregate with no State record. An aggregate owns one unit of business state, and that state changes in a single step. Lifecycle flags scattered across properties let callers combine states the business never allows, so each aggregate carries its lifecycle in a State record instead.

## Reference

### What the Rule Enforces

LS1003 enforces [Model every Aggregate lifecycle with state records](../../packs/dotnet/domain.md#model-every-aggregate-lifecycle-with-state-records) (`litespec/packs/dotnet/domain#model-every-aggregate-lifecycle-with-state-records`). It runs in Domain only. Its category is `LiteSpec.Domain`. Severity and enablement follow the [Analyzers overview](../README.md). It decides at the end of compilation, as the [Analyzers overview](../README.md) describes.

### What the Rule Reports

The rule recognizes an aggregate by a base class named `AggregateRoot` with one type argument, and reports it when it exposes no `State` property typed as an abstract record. It walks the inheritance chain up to the `AggregateRoot` base, so an inherited `State` property counts. The diagnostic sits on the aggregate name.

### Failing Example

```csharp
public sealed class Order : AggregateRoot<OrderId>
{
    public Order(OrderId id) : base(id) { }
}
```

### Passing Example

```csharp
public sealed class Order : AggregateRoot<OrderId>
{
    public Order(OrderId id, OrderState state) : base(id) { State = state; }
    public OrderState State { get; }
}

public abstract record OrderState;

public sealed record OrderDraftState : OrderState;

public sealed record OrderPlacedState(DateTimeOffset PlacedAt) : OrderState;
```

### How to Fix

Give the aggregate a `State` property typed as an abstract `{Aggregate}State` record, with one sealed record per lifecycle state derived from it.

## Notes

### What the Rule Ignores

A class that is not an aggregate never reports, and neither does an aggregate whose `State` property already is an abstract record. The rule does not run outside Domain.
