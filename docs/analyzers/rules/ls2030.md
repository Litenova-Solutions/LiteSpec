# LS2030: Contracts Project Declares an Interface

LS2030 reports an interface declared in a Contracts project. A Contracts project publishes data only, grouped by aggregate: identifiers, facts, and public queries with their results. A consumer that needs behavior from another module declares its own port and implements it with an adapter, so an interface in the provider's contracts describes a call nobody may make.

## Reference

### What the Rule Enforces

LS2030 enforces [Publish Only Data from Each Contracts Project](../../backend/dotnet/architecture.md#publish-only-data-from-each-contracts-project) (`litespec/backend/dotnet/architecture#publish-only-data-from-each-contracts-project`). It runs in every layer except Test. Its category is `LiteSpec.Layers`. Severity and enablement follow the [Analyzers overview](../README.md).

### What the Rule Reports

An interface reports when a Contracts file declares it: a file under a nested `Contracts/` folder or in a sibling `{Product}.{Module}.Contracts` project. The diagnostic sits on the interface name, and its message names the interface.

### Failing Example

```csharp
namespace Claimwick.Books.Contracts.Books;

internal interface IBookReader
{
}
```

The interface sits in the books module Contracts, where only data may live.

### Passing Example

```csharp
namespace Claimwick.Books.Contracts.Books;

internal sealed record BookLent(System.Guid Book);
```

The fact is data, so it belongs in Contracts. The consumer declares its own port in its `Ports/` folder instead.

### How to Fix

Move the behavior to the consumer: declare a port in the consumer's `Ports/{Provider}/` folder naming the consumer's own types, and implement it with an adapter in `Infrastructure/{Provider}/` that sends the provider's public queries. Delete the interface from Contracts.

## Notes

### What the Rule Ignores

An interface in a module `Ports/` folder, a record, class, struct, or enum in a Contracts project, and a type in a Test file never report. A nested interface inside a Contracts type reports like a top-level one.
