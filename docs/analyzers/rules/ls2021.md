# LS2021: Message Sent Outside an Entry Point

## Intent

LS2021 is a compiler check that reports a type holding a command, query or event mediator when the type is not an endpoint, a reaction or a job, because only those three entry points send a use case message. This page states what the rule reports, where the error sits, and how to move the send to the entry point that owns it.

## Reference

### What the Rule Enforces

LS2021 enforces [Keep Command Handlers to Load, Call and Stage](../../backend/application.md#keep-command-handlers-to-load-call-and-stage) (`litespec/backend/application#keep-command-handlers-to-load-call-and-stage`). It runs in Domain, Application, and Infrastructure. Its category is `LiteSpec.Layers`. Severity and enablement follow the [Analyzers overview](../README.md).

### What the Rule Reports

The rule reports a constructor parameter, a field, or a property whose type is `ICommandMediator`, `IQueryMediator`, or `IEventMediator`, held by a type that is not an entry point. An entry point is a type that implements `IEventHandler<T>` (a reaction), a type that derives from `BackgroundService` or whose name ends in `Job` (a job), or a type whose name ends in `Endpoint` (an endpoint). The diagnostic sits on the mediator type, and its message names the holding type and the mediator.

### Failing Example

```csharp
namespace Claimwick.Spending.Expenses.UseCases.ApproveExpense;

internal sealed class ApproveExpenseCommandHandler(ICommandMediator commands)
{
}
```

with the file in `Spending/Expenses/UseCases/ApproveExpense/Application/`. A command handler loads an expense, calls one act on it, and stages it. The follow-on command belongs to a reaction that runs after the commit.

### Passing Example

```csharp
namespace Claimwick.Spending.Expenses.UseCases.ApproveExpense;

internal sealed class SubmitPayoutOnExpenseApprovedHandler(ICommandMediator commands)
    : IEventHandler<ExpenseApprovedEvent>
{
}
```

with the file in `Spending/Expenses/UseCases/ApproveExpense/Application/`. The reaction implements `IEventHandler<T>`, so it is an entry point and may hold the command mediator. It sends the one use case message it runs.

### How to Fix

Remove the mediator from the type, and send the follow-on message from a reaction on the event the handler raised. The reaction sits in the `Application/` folder of the use case it runs, and it holds the command mediator. A job that runs a command over many records is an entry point as well.

## Notes

### What the Rule Ignores

The rule does not report a parameter of a method that is not a constructor, so a method that takes a mediator as an argument is not checked. It does not report a type in the shared kernel, which composes the pipeline and holds the mediators by design. It does not run in a Test file or in a file the layer rules cannot place. The mediator itself is checked by [LS2022](ls2022.md) where it publishes events.
