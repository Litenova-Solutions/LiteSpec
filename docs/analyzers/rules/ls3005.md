# LS3005: Class or Struct Declares a Primary Constructor

LS3005 reports a class or struct that declares a primary constructor. A primary constructor parameter is captured, mutable, and visible in the whole class body with no read-only mark, so an explicit constructor with private read-only fields states the same intent more plainly.

## Reference

### What the Rule Enforces

LS3005 enforces [Avoid Primary Constructors on Classes and Structs](../../workspace/naming.md#avoid-primary-constructors-on-classes-and-structs) (`litespec/workspace/naming#avoid-primary-constructors-on-classes-and-structs`). It runs in every production layer. Its category is `LiteSpec.Style`. The rule reports at info severity, so it never fails the build on its own; a project that wants it to fail raises it in `.editorconfig`, as the [Analyzers overview](../README.md) describes.

### What the Rule Reports

A class or struct declaration reports when it carries a parameter list. The diagnostic sits on the parameter list, and its message names the type.

### Failing Example

```csharp
internal sealed class SubmitExpenseCommandHandler(IExpenseRepository expenses)
{
    public void Handle(SubmitExpenseCommand command)
    {
    }
}
```

The handler captures `expenses` as a mutable parameter visible in the whole body.

### Passing Example

```csharp
internal sealed class SubmitExpenseCommandHandler
{
    private readonly IExpenseRepository _expenses;

    public SubmitExpenseCommandHandler(IExpenseRepository expenses)
    {
        _expenses = expenses;
    }

    public void Handle(SubmitExpenseCommand command)
    {
    }
}
```

The field states that the dependency never changes, and the constructor holds the validation when the handler needs it.

### How to Fix

Declare a private read-only field per parameter and an explicit constructor that assigns them. Keep positional records as they are: records stay allowed for immutable data.

## Notes

### What the Rule Ignores

Records and record structs never report: positional parameters define immutable data there. A name in a Test file, or in a file the layer rules cannot place, never reports.
