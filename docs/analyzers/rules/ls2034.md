# LS2034: Mediator Call Without Explicit Mediation Settings

LS2034 reports a command or query mediator call in an event handler that lists no explicit mediation settings. The handler runs with no caller, so the nested use case is refused for its access or runs under the wrong identity. State the identity on the call.

## Reference

### What the Rule Enforces

LS2034 enforces [Pass Explicit Mediation Settings to Nested Use Cases](../../packs/dotnet/application.md#pass-explicit-mediation-settings-to-nested-use-cases) (`litespec/packs/dotnet/application#pass-explicit-mediation-settings-to-nested-use-cases`). It runs in Application, Infrastructure, and Worker. Its category is `LiteSpec.Layers`. Severity and enablement follow the [Analyzers overview](../README.md).

### What the Rule Reports

The rule reports `SendAsync` on `ICommandMediator` or `QueryAsync` on `IQueryMediator` inside a class implementing `IEventHandler` or `IDomainEventReaction`, where every argument past the message is the cancellation token or is absent. Any other argument counts as the explicit mediation settings.

The diagnostic sits on the method name, and its message states the handler and the method.

### Failing Example

```csharp
internal sealed class MarkBookLentOnLoanBorrowedHandler : IEventHandler<LoanBorrowedDomainEvent>
{
    public Task HandleAsync(LoanBorrowedDomainEvent @event, CancellationToken cancellationToken) =>
        _commandMediator.SendAsync(new MarkBookLentCommand(@event.BookId, @event.LoanId), cancellationToken);
}
```

### Passing Example

```csharp
internal sealed class MarkBookLentOnLoanBorrowedHandler : IEventHandler<LoanBorrowedDomainEvent>
{
    public Task HandleAsync(LoanBorrowedDomainEvent @event, CancellationToken cancellationToken) =>
        _commandMediator.SendAsync(new MarkBookLentCommand(@event.BookId, @event.LoanId), MediationSettings.System, cancellationToken);
}
```

### How to Fix

Pass the mediation settings carrying the identity the nested use case runs under, beside the message and the cancellation token.

## Notes

### What the Rule Ignores

A call that passes any argument besides the message and the cancellation token never reports. A dispatch outside an event handler never reports: endpoints and use case handlers run with a caller, and jobs stay outside this rule. The rule does not run in Domain, Ports, or WebApi.
