# LS1002: Domain Declares an Enum

LS1002 reports any enum declared in Domain. A closed set of domain values needs behavior and a stable code for callers outside Domain, and an enum carries neither.

## Reference

### What the Rule Enforces

LS1002 enforces [Model every closed set of domain values without enums](../../packs/dotnet/domain.md#model-every-closed-set-of-domain-values-without-enums) (`litespec/packs/dotnet/domain#model-every-closed-set-of-domain-values-without-enums`). It runs in Domain only. Its category is `LiteSpec.Domain`. Severity and enablement follow the [Analyzers overview](../README.md).

### What the Rule Reports

The rule reports each enum declared in Domain, with the diagnostic on the enum name.

### Failing Example

```csharp
namespace Shop.Orders.Domain;

public enum OrderStatus { Draft, Placed }
```

### Passing Example

```csharp
namespace Shop.Orders.Domain;

public abstract record OrderStatus(string Code);

public sealed record Draft() : OrderStatus("draft");
```

### How to Fix

Replace the enum with an abstract record base with one sealed record per case: expose a stable `Code` on the base and convert labels through `FromCode`.

## Notes

### What the Rule Ignores

A record hierarchy never reports. The rule does not run outside Domain.
