# LS2039: Knowledge Set Declares Logic

LS2039 reports a method, constructor, property, or field in a knowledge set whose body holds logic. A set holds only rows built through its model's constructors; behavior a variant needs lives in the model as a strategy the set selects with data.

## Reference

### What the Rule Enforces

LS2039 enforces [Keep Knowledge Sets Free of Logic](../../backend/knowledge.md#keep-knowledge-sets-free-of-logic) (`litespec/backend/knowledge#keep-knowledge-sets-free-of-logic`). It runs on knowledge set files: files in a project under `src/Knowledge/` named `<Product>.<Area>.<Variant>`. Its category is `LiteSpec.Layers`. Severity and enablement follow the [Analyzers overview](../README.md).

### What the Rule Reports

A member reports when its body, arrow clause, accessor, or initializer holds a branch, a loop, a switch, a call, or a throw: an `if` statement, a `for`, `foreach`, `while`, or `do` loop, a `switch` statement or expression, an invocation, or a `throw`. Object and collection creation pass, so a `static readonly` field or a get-only property initialized with `new` stays quiet. The diagnostic sits on the member name, and its message names the member.

### Failing Example

```csharp
namespace Claimwick.Travel.France.Rates;

public sealed class FranceRates
{
    public decimal For(string code)
    {
        if (code.Length == 0)
        {
            return 0m;
        }

        return 1m;
    }
}
```

### Passing Example

```csharp
namespace Claimwick.Travel.France.Rates;

public sealed record PerDiemRow(string Country, decimal Amount);

public sealed class FranceRates
{
    private static readonly PerDiemRow Default = new("FR", 42m);

    public PerDiemRow Current { get; } = new("FR", 42m);

    public PerDiemRow For() => new("FR", 42m);
}
```

### How to Fix

Move the behavior into the knowledge model as a strategy the set selects with data, or restate the member as rows built through the model's constructors.

## Notes

### What the Rule Ignores

The rule runs only in a knowledge set compilation, so the same member outside a set never reports. A body that only returns or constructs rows never reports: member access, element access, object and collection creation, an auto-property, and a record positional parameter list all pass. Implicitly declared members, local functions, and property accessors reached through their property never report on their own; the enclosing member carries the diagnostic.
