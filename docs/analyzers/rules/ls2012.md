# LS2012: Handler Authorizes Itself

## Intent

LS2012 is a compiler check that reports a command or query handler, the type that runs a use case, throwing an access refusal itself instead of leaving authorization to the pipeline guard. This page states what the rule reports, where the error sits, and how to move the check into the declared access.

## Reference

### What the Rule Enforces

LS2012 enforces [Enforce target authorization in the pipeline](../../backend/application.md#enforce-target-authorization-in-the-pipeline) (`litespec/backend/application#enforce-target-authorization-in-the-pipeline`). It runs in Application and Infrastructure. Its category is `LiteSpec.Layers`. It reports an error and is enabled by default, as the [Analyzers overview](../README.md) describes.

### What the Rule Reports

The rule reports a command or query handler, which is a class whose name ends in `CommandHandler` or `QueryHandler`, or that implements `ICommandHandler` or `IQueryHandler`, that throws an exception type whose name ends in `ForbiddenException`, `UnauthorizedException`, or `AccessDeniedException`. For a `throw new` the diagnostic sits on the created exception type; for any other thrown value it sits on that value. Its message names the handler and the exception.

### Failing Example

```csharp
internal sealed class RenewLoanCommandHandler
{
    public void Handle(RenewLoanCommand command)
    {
        throw new LoanForbiddenException();
    }
}
```

### Passing Example

```csharp
internal sealed class RenewLoanCommandHandler(ILoanRepository loanRepository)
{
    public void Handle(RenewLoanCommand command)
    {
        var loan = loanRepository.GetById(command.LoanId);
        loanRepository.Store(loan);
    }
}
```

### How to Fix

Declare the grant on the use-case record and let the authorization guard enforce it before the handler runs, so the handler never compares the caller with a target and never throws the forbidden refusal itself.

## Notes

### What the Rule Ignores

The rule does not report a throw of any other exception type, a throw in an event handler or a job, or a rethrow without a value. It does not run in Domain, Application.Abstractions, or WebApi.
