# LS2023: Class Implements Two Message Definitions

LS2023 reports a class that implements two LiteBus message definition contracts. Each pipeline declaration sits in its own class: who may send a message and how the audit trail records it change for different reasons and are read by different reviews, so they never share a file.

## Reference

### What the Rule Enforces

LS2023 enforces [Declare Each Pipeline Concern in Its Own Class](../../workspace/design.md#declare-each-pipeline-concern-in-its-own-class) (`litespec/workspace/design#declare-each-pipeline-concern-in-its-own-class`). It runs in every production layer. Its category is `LiteSpec.Layers`. Severity and enablement follow the [Analyzers overview](../README.md).

### What the Rule Reports

A class reports when it implements two distinct `IMessageDefinition<TMessage, TValue>` contracts, in any namespace, whether directly or through the concern interfaces derived from them. The diagnostic sits on the class name, and its message names the split into one class per concern.

### Failing Example

```csharp
internal sealed class SubmitExpenseCommandDefinition
    : IAuthorizationDefinition<SubmitExpenseCommand>, IAuditDefinition<SubmitExpenseCommand>
{
}
```

One class declares both the authorization and the audit of the message.

### Passing Example

```csharp
internal sealed class SubmitExpenseCommandAuthorizationDefinition
    : IAuthorizationDefinition<SubmitExpenseCommand>
{
}

internal sealed class SubmitExpenseCommandAuditDefinition
    : IAuditDefinition<SubmitExpenseCommand>
{
}
```

Each concern has its own class, named `{Message}{Concern}Definition`, and each implements exactly one definition interface.

### How to Fix

Split the class into one class per concern, each implementing exactly one definition interface. The handler keeps the use case mark; definitions carry no mark.

## Notes

### What the Rule Ignores

A class implementing one definition contract, or none, never reports. Interfaces, structs, and records that are not classes never report. A name in a Test file, or in a file the layer rules cannot place, never reports.
