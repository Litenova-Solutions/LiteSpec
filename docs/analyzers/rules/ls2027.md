# LS2027: Application Does Infrastructure Work

LS2027 reports an Application file that names an archive, serialization, or document library. Producing a file format, rendering, and parsing are Infrastructure behind an Application port, even when the code uses only the base class library.

## Reference

### What the Rule Enforces

LS2027 enforces [Produce File Formats in Infrastructure](../../backend/architecture.md#produce-file-formats-in-infrastructure) (`litespec/backend/architecture#produce-file-formats-in-infrastructure`). It runs in Application only. Its category is `LiteSpec.Layers`. Severity and enablement follow the [Analyzers overview](../README.md).

### What the Rule Reports

A name in an Application file reports when it resolves to a type in one of these namespaces, followed by a dot or the end of the name:

```text
System.IO.Compression
System.Text.Json
CsvHelper
Csv
ClosedXML
EPPlus
NPOI
iTextSharp
itext
PdfSharp
QuestPDF
DinkToPdf
PuppeteerSharp
SkiaSharp
SixLabors
```

The diagnostic sits on the name, and its message names the type and its namespace.

### Failing Example

```csharp
using System.IO.Compression;

namespace Claimwick.Export.Application.ExportWorkspace;

internal sealed class ExportWorkspaceQueryHandler
{
    public void Handle()
    {
        using var archive = ZipFile.Open("export.zip", ZipArchiveMode.Create);
    }
}
```

The handler writes the archive itself instead of calling the use case's port.

### Passing Example

```csharp
namespace Claimwick.Export.Application.ExportWorkspace;

internal sealed class ExportWorkspaceQueryHandler
{
    private readonly IWorkspaceArchiveWriter _writer;

    public ExportWorkspaceQueryHandler(IWorkspaceArchiveWriter writer)
    {
        _writer = writer;
    }

    public void Handle(WorkspaceArchiveInput input)
    {
        _writer.Write(input);
    }
}
```

The handler hands the gathered input to the port, and the writer in the use case's `Infrastructure/` folder produces the archive.

### How to Fix

Declare a port beside the use case it serves and move the file, archive, or document work into its Infrastructure implementation. Keep the small shapes of the implementation as private nested types.

## Notes

### What the Rule Ignores

A name in a Domain, Infrastructure, WebApi, Worker, or Test file never reports: the rule runs in Application only. A namespace that only shares a prefix, such as `CsvReader.Utils` for `Csv`, does not match; the match needs a dot or the end of the name after the prefix. A name that resolves to no type never reports.
