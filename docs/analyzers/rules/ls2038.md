# LS2038: Module References a Knowledge Set

LS2038 reports a module file that names a type of a knowledge set project. A module reads knowledge through the knowledge model, which answers lookups by key or role and date; only hosts reference a set, to register it. Naming a set type couples the module to one variant's values.

## Reference

### What the Rule Enforces

LS2038 enforces [Read Knowledge Through Its Model](../../core/knowledge.md#read-knowledge-through-its-model) (`litespec/core/knowledge#read-knowledge-through-its-model`). It runs in every layer except Test. Its category is `LiteSpec.Layers`. Severity and enablement follow the [Analyzers overview](../README.md).

### What the Rule Reports

A name reports when it resolves to a type in a knowledge set: a type declared in a project under `src/Knowledge/` named `<Product>.<Area>.<Variant>`, or a type from a referenced assembly of that shape whose model the compilation also references. The diagnostic sits on the name, and its message names the type and the set.

### Failing Example

```csharp
namespace Claimwick.Spending.Application.SubmitExpense;

internal sealed class SubmitExpenseCommandHandler
{
    private FranceRates? _rates;
}
```

with `FranceRates` declared in the `Claimwick.Travel.France` knowledge set project.

### Passing Example

```csharp
namespace Claimwick.Spending.Application.SubmitExpense;

internal sealed class SubmitExpenseCommandHandler
{
    private TravelRates? _rates;
}
```

with `TravelRates` declared in the `Claimwick.Travel` knowledge model project.

### How to Fix

Read the knowledge through the model: ask the model's runtime for the rule by role and date instead of naming the set type.

## Notes

### What the Rule Ignores

A name in a Test file, in a host, in a knowledge model or set file, or in a file the layer rules cannot place, never reports. The rule leaves alone a type in a knowledge model project, and a referenced assembly of the set shape when the compilation does not also reference its model. A sibling `Contracts` project never counts as a set.
