# LS2033: LoadMany on a Typed-Identifier Document

LS2033 reports a Marten multi-load of documents whose id member is a typed identifier. Marten refuses the call, so the read fails at run time. Load one document at a time, or query by the underlying value.

## Reference

### What the Rule Enforces

LS2033 enforces [Load Documents Keyed by Typed Identifiers One at a Time](../../backend/dotnet/persistence.md#load-documents-keyed-by-typed-identifiers-one-at-a-time) (`litespec/backend/dotnet/persistence#load-documents-keyed-by-typed-identifiers-one-at-a-time`). It runs in Application, Infrastructure, and Worker. Its category is `LiteSpec.Layers`. Severity and enablement follow the [Analyzers overview](../README.md).

### What the Rule Reports

The rule reports `LoadManyAsync` or `LoadMany` on `IDocumentSession` or `IQuerySession` whose document type argument carries an instance `Id` property or field typed as a typed identifier: a struct named `*Id` or implementing `IStronglyTypedId`. The diagnostic sits on the method name, and its message names the method and the document.

### Failing Example

```csharp
public Task<IReadOnlyList<Expense>> HandleAsync(Guid[] ids, CancellationToken cancellationToken) =>
    _session.LoadManyAsync<Expense>(ids, cancellationToken);
```

with `ExpenseId Id` on `Expense`.

### Passing Example

```csharp
public async Task<IReadOnlyList<Expense>> HandleAsync(ExpenseId[] ids, CancellationToken cancellationToken)
{
    var expenses = new List<Expense>();
    foreach (var id in ids)
    {
        var expense = await _session.LoadAsync<Expense>(id, cancellationToken);
        if (expense is not null)
        {
            expenses.Add(expense);
        }
    }

    return expenses;
}
```

### How to Fix

Load one document at a time where the list is short, or query the documents by their underlying values where it is not.

## Notes

### What the Rule Ignores

A document whose `Id` is a plain value never reports, and neither does a `LoadMany` call on any other type or a call with no document type argument. Only the member named `Id` counts as the identity. The rule does not run in Domain, Ports, or WebApi.
