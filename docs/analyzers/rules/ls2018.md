# LS2018: File Names a Type Outside Its Layer

Layers point inward: Application names Domain, and WebApi maps HTTP onto commands without touching storage or domain rules. A reference against that direction couples a file to work its layer never owns. LS2018 reports an Application or WebApi file that names a type outside its layer.

## Reference

### What the Rule Enforces

LS2018 enforces [Follow Layer Direction in Every File](../../backend/dotnet/architecture.md#follow-layer-direction-in-every-file) (`litespec/backend/dotnet/architecture#follow-layer-direction-in-every-file`). It runs in Application and WebApi. Its category is `LiteSpec.Layers`. Severity and enablement follow the [Analyzers overview](../README.md).

### What the Rule Reports

A name in an Application file reports when it resolves to an Infrastructure or WebApi type, an ASP.NET Core type, or an `HttpContext`. A name in a WebApi file reports when it resolves to an Infrastructure type, a repository, or a Domain type other than a typed identifier or a shared-kernel value. The diagnostic sits on the name, and its message names the file's layer, the type, and why the layer may not name it.

### Failing Example

```csharp
using Microsoft.AspNetCore.Http;

internal sealed class SubmitExpenseCommandHandler(IHttpContextAccessor http)
{
}
```

### Passing Example

```csharp
internal sealed class SubmitExpenseCommandHandler(IExpenseRepository expenses, IClock clock)
{
}
```

### How to Fix

Use only the types the file's layer allows: repositories, ports, and the clock in Application, and the mediator with request and response models in WebApi. Move web input the handler reads into the endpoint, which maps it onto the command before dispatch.

## Notes

### What the Rule Ignores

A name in a Domain, Infrastructure, Worker, or Test file never reports: the rule runs in Application and WebApi only. From WebApi it leaves alone a typed identifier, which is a type whose name ends in `Id`, and a shared-kernel value, which is a type in the product `Domain/` folder. A name that resolves to no project source file never reports.
