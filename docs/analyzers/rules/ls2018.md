# LS2018: File Names a Type Outside Its Layer

LS2018 reports an Application, Ports, or WebApi file that names a type outside its layer. Layers point inward: Application names Domain, and WebApi maps HTTP onto commands without touching storage or domain rules, so a reference against that direction couples a file to work its layer never owns.

## Reference

### What the Rule Enforces

LS2018 enforces [Follow Layer Direction in Every File](../../packs/dotnet/architecture.md#follow-layer-direction-in-every-file) (`litespec/packs/dotnet/architecture#follow-layer-direction-in-every-file`). It runs in Application, Ports, and WebApi. Its category is `LiteSpec.Layers`. Severity and enablement follow the [Analyzers overview](../README.md).

### What the Rule Reports

A name in an Application file reports when it resolves to an Infrastructure or WebApi type, an ASP.NET Core type, or an `HttpContext`. Port interfaces stay allowed: they are the module ports the handler calls. Platform types stay allowed as well, since Application builds on platform abstractions.

A name in a Ports file reports when it resolves to an Application, Infrastructure, or WebApi type. A name in a WebApi file reports when it resolves to an Infrastructure type, a repository, a port, or a Domain type other than a typed identifier or a shared-kernel value.

The diagnostic sits on the name, and its message states the file's layer, the type, and why the layer cannot use it. When the Infrastructure type is a stored document of an aggregate, the message states the fix: query the aggregate type through `IQuerySession` instead of referencing the Infrastructure document type.

### Failing Example

```csharp
using Microsoft.AspNetCore.Http;

internal sealed class SubmitExpenseCommandHandler
{
    private readonly IHttpContextAccessor _http;

    public SubmitExpenseCommandHandler(IHttpContextAccessor http)
    {
        _http = http;
    }
}
```

### Passing Example

```csharp
internal sealed class SubmitExpenseCommandHandler
{
    private readonly IExpenseRepository _expenses;
    private readonly IClock _clock;

    public SubmitExpenseCommandHandler(IExpenseRepository expenses, IClock clock)
    {
        _expenses = expenses;
        _clock = clock;
    }
}
```

### How to Fix

Use only the types the file's layer allows: repositories, ports, and the clock in Application, and the mediator with request and response models in WebApi. Move web input the handler reads into the endpoint, which maps it onto the command before dispatch.

## Notes

### What the Rule Ignores

A name in a Domain, Infrastructure, Worker, or Test file never reports: the rule runs in Application, Ports, and WebApi only. From WebApi it leaves alone a typed identifier, which is a type whose name ends in `Id`, and a shared-kernel value, which is a type in the product `Domain/` folder or in the Kernel project. A name that resolves to no project source file never reports.
