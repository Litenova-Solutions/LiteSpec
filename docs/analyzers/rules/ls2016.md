# LS2016: Handler Takes a Pipeline-Owned Collaborator

LS2016 reports a handler that takes a pipeline-owned collaborator as a constructor parameter. The pipeline owns the commit through collaborators such as the unit of work and the outbox, while a handler's own job is load, call, and stage.

## Reference

### What the Rule Enforces

LS2016 enforces [Keep Pipeline-Owned Collaborators Out of Handlers](../../packs/dotnet/persistence.md#keep-pipeline-owned-collaborators-out-of-handlers) (`litespec/packs/dotnet/persistence#keep-pipeline-owned-collaborators-out-of-handlers`). It runs in Application, Infrastructure, and Worker. Its category is `LiteSpec.Layers`. Severity and enablement follow the [Analyzers overview](../README.md).

### What the Rule Reports

A command or query handler is a class whose name ends in `CommandHandler` or `QueryHandler`, or that implements `ICommandHandler` or `IQueryHandler`. It reports when it takes a constructor parameter whose full type name is listed in the `litespec.LS2016.pipeline_owned_types` key. The diagnostic sits on the parameter type, and its message names the handler and the collaborator.

### Failing Example

```csharp
internal sealed class RenewLoanCommandHandler
{
    private readonly IUnitOfWork _unitOfWork;

    public RenewLoanCommandHandler(IUnitOfWork unitOfWork)
    {
        _unitOfWork = unitOfWork;
    }
}
```

### Passing Example

```csharp
internal sealed class RenewLoanCommandHandler
{
    private readonly ILoanRepository _loanRepository;

    public RenewLoanCommandHandler(ILoanRepository loanRepository)
    {
        _loanRepository = loanRepository;
    }
}
```

### How to Fix

Take only the repositories named by the record's writes and reads. The pipeline owns the unit of work, idempotency, and the outbox, and persistence owns uniqueness claims.

### Configuration

The comma-separated `.editorconfig` key `litespec.LS2016.pipeline_owned_types` lists the full type names the rule reports. When the key is absent or empty, the rule reports these defaults:

- `LiteBus.Messaging.Abstractions.IUnitOfWork`
- `LiteBus.Messaging.Abstractions.IIdempotencyStore`
- `LiteBus.Outbox.Abstractions.ITransactionalOutbox`
- `LiteBus.Outbox.Abstractions.IOutbox`

A project adds its uniqueness claim service to the same key:

```ini
litespec.LS2016.pipeline_owned_types = LiteBus.Messaging.Abstractions.IUnitOfWork, LiteBus.Messaging.Abstractions.IIdempotencyStore, LiteBus.Outbox.Abstractions.ITransactionalOutbox, LiteBus.Outbox.Abstractions.IOutbox, Loans.Holds.IHoldClaimService
```

## Notes

### What the Rule Ignores

A constructor parameter whose type is not listed never reports. Neither does a collaborator taken outside a constructor, or a handler that is neither a command nor a query handler. The rule does not run in Domain or WebApi.
