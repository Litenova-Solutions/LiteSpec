# LS2025: Use-Case Infrastructure Names a Type Outside Its Layer

LS2025 reports a use case's `Infrastructure/` folder that names a Domain type outside typed identifiers and shared values, or a WebApi type. The use-case adapter implements the use case's own ports from platform and library types; domain rules and HTTP stay out of it.

## Reference

### What the Rule Enforces

LS2025 enforces [Follow Layer Direction in Every File](../../backend/dotnet/architecture.md#follow-layer-direction-in-every-file) (`litespec/backend/dotnet/architecture#follow-layer-direction-in-every-file`). It runs on Infrastructure files inside a use case folder. Its category is `LiteSpec.Layers`. Severity and enablement follow the [Analyzers overview](../README.md).

### What the Rule Reports

A name in an `Infrastructure/{UseCase}/` file reports when it resolves to a Domain type other than a typed identifier or a shared-kernel value, or to a WebApi type. A typed identifier is a type whose name ends in `Id`, and a shared-kernel value is a type in the Kernel project or outside every module. The diagnostic sits on the name, and its message names the type and why the layer may not name it.

### Failing Example

```csharp
namespace Claimwick.Export.Infrastructure.ExportWorkspace;

internal sealed class WorkspaceArchiveWriter : IWorkspaceArchiveWriter
{
    public void Write(Expense expense)
    {
    }
}
```

with the file in `Export/Infrastructure/ExportWorkspace/` and `Expense` the aggregate root. The writer takes the aggregate instead of the gathered input the handler passes it.

### Passing Example

```csharp
namespace Claimwick.Export.Infrastructure.ExportWorkspace;

internal sealed class WorkspaceArchiveWriter : IWorkspaceArchiveWriter
{
    public void Write(WorkspaceArchiveInput input)
    {
    }
}
```

The writer takes the input record the handler gathered, and names no Domain type.

### How to Fix

Pass the adapter only the input it needs: the handler gathers plain data and hands it to the use case's port, and the adapter works from that input with platform and library types.

## Notes

### What the Rule Ignores

A file outside every use case folder never reports, so shared `Infrastructure/` folders are left to review. A name that resolves to no project source file never reports. References between two use cases' folders stay with LS2019.
