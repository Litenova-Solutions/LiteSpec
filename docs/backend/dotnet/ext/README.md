# Overview

A .NET backend can switch on one extension it alone offers: executable acceptance scenarios in business language. A use case is one command or query, a flow is the steps to one goal, and a module is one business area. A local extension activates per use case, flow, or module wherever its criterion holds. Use it when shared examples need business-language review.

## How the Pages Fit Together

The shared [Extensions overview](../../../ext/README.md) catalog holds the extensions any stack can select. The page below belongs to the .NET stack because it binds to its runners, packages, and providers. It states its activation criterion, the baseline provisions it replaces, and the records it switches on. The BDD page replaces nothing and switches on scenario records.
