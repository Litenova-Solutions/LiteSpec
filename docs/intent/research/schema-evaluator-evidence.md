# Schema Evaluator Evidence

## Answer

Read on 2026-11-09, every JsonSchema.Net release from 9.0.0 (2026-02-01) on, with Json.More.Net and JsonPointer.Net, ships under [the Open Source Maintenance Fee agreement][jsonschema-net-eula] instead of MIT. The agreement charges a fee to a user with annual gross revenue of US$10,000 or more who uses the published binaries in revenue-generating activities, and exempts binaries compiled from the MIT source. Version 8.0.5 (2025-12-28) is the last MIT release. LiteSpec's tools validated every schema through 9.6.0, and the native CLI compiled it into each executable.

Two free libraries remain. [LateApexEarlySpeed.Json.Schema][lateapexearlyspeed] 4.2.4 is BSD-3-Clause, maintained, and downloaded about 315,000 times, but it targets only netstandard2.1, depends on Microsoft.Extensions.Http 3.1.0 for remote references, and claims no Native AOT support. [FormFinch.JsonSchemaValidation][formfinch] 1.2.0 has four releases and about 1,400 downloads. LiteSpec's seven schemas use about 25 keywords of draft 2020-12, every `$ref` a local `#/$defs/` pointer, and no dynamic reference, anchor or unevaluated keyword, while LiteSpec already renders every message itself from the library's result tree.

[The evaluator][schema-evaluator] implements the draft 2020-12 assertions and applicators without dynamic references, anchors, `unevaluatedProperties`, `unevaluatedItems` and `contentSchema`. A comparison harness ran it and the library-based renderer over 378 real instances in the repository, records, project files, glossaries, catalogs, locks and the manifest, and 25 seeded mutations of each: 9,828 cases, 8,156 of them failing. The output matched message for message in 9,666 cases. The other 162 were one defect of the library-based renderer: when a schema failed for one reason, it also reported the rejected shape of a `oneOf` or `anyOf` that passed, such as a missing `url` on a research source that names its `path`. With that defect reproduced in the evaluator, all 9,828 cases matched.

Against [the JSON Schema Test Suite][test-suite] at commit `245a45a`, the evaluator ran the 761 draft 2020-12 cases of the keywords it implements, leaving out 49 that use remote references, `$id`, anchors or unevaluated keywords. It agreed with the expected result in 757. The 4 others use the ECMAScript Unicode property name `\p{Letter}`, which a .NET regular expression writes `\p{L}`; no LiteSpec schema uses either. The library-based renderer had passed 21 suite cases silently that the evaluator now reports: a `false` subschema anywhere but `additionalProperties` rejected the value without a message.

## Notes on Sources

Five sources were read on 2026-11-09. `jsonschema-net-eula` is the licence file of JsonSchema.Net 9.6.0, read for the fee terms and the exemption for self-compiled binaries; the licence of every other release was read from its package metadata. `lateapexearlyspeed` and `formfinch` are the NuGet listings of the two free libraries, read for licence, release history, downloads and dependencies. `test-suite` is the official JSON Schema Test Suite, read for the draft 2020-12 cases. `schema-evaluator` is the evaluator itself. The case counts and the comparison results are the researcher's own measurements, carried in the Answer.
