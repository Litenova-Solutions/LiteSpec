# Overview

The svelte pack binds LiteSpec to a Svelte web frontend. Selecting `svelte` applies every page in this folder with its checks and lints. Read the pages below in order when starting frontend work, then load only the pages each task touches.

## Reading Order

- [Stack](stack.md): rendering modes, file layout, data loading, and the pinned versions.
- [Structure](structure.md): the frame, routes, and modules layout with use-case marks.
- [Data](data.md): the generated client, the problem type, and the shared form entry point.
- [Components](components.md): composites, page-code refusals, and typed boundaries.
- [Rendering](rendering.md): route metadata and the error surface.
- [UI Primitives](ui-primitives.md): the visual reference, locked primitives, spacing and height, and the route lint bans.
- [Testing](testing.md): Vitest logic tests and Playwright route and evidence tests.
