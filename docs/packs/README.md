# Overview

The packs bind LiteSpec to one technology. A project selects its packs beside the Core pages: one backend pack for a server project, and one pack per frontend. Selecting a pack applies every page in its folder with its checks and readers.

Read the [Core Overview](../core/README.md) first for the shared rules, then load only the packs the project selects.

## Packs

- [dotnet](dotnet/README.md): the .NET backend stack, from domain types to the HTTP API, tests, and workspace layout.
- [svelte](svelte/README.md): the Svelte web frontend stack, from routes and structure to shared UI primitives and tests.
- [android](android/README.md): the native Android stack, from screens and navigation to resource tokens and tests.
