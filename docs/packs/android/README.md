# Overview

The android pack binds LiteSpec to a native Android application built with .NET for Android. Selecting `android` applies every page in this folder with its checks. Read the pages below in order when starting mobile work, then load only the pages each task touches.

## Reading Order

- [Stack](stack.md): the platform project, navigation controller, screens, and versions.
- [Structure](structure.md): the solution tree, core projects, screen folders, and adapters.
- [Screens](screens.md): native views, the controller, app links, back, insets, and accessibility.
- [Data](data.md): the typed store, app-private storage, and the generated client.
- [Device](device.md): pickers, permissions, audio focus, and declared capabilities.
- [UI Primitives](ui-primitives.md): single-job screens, bottom navigation, resource tokens, and visual calibration.
- [Testing](testing.md): plain .NET core tests and on-device screen tests.
