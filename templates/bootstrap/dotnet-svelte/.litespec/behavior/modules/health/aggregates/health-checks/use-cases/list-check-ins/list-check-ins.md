# List Check-ins

List Check-ins is how the web list shows the stored check-ins newest first, bounded to the latest hundred. The list offers to record a new check-in beside the rows.

## Flow

1. The visitor opens the check-ins list.
2. Health returns the check-ins newest first.

## Example

Ava recorded two check-ins, one yesterday and one this morning. She opens the check-ins list, and both rows show newest first with the recorded moment, the note, and the Recorded state of each.
