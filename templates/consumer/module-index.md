# __PROJECT__ Module Specifications

This directory contains one folder per domain module. Each folder has one `README.md` module specification and one Markdown file per use case.

```text
modules/
  README.md
  orders/
    README.md
    create-order.md
    cancel-order.md
```

End-to-end flows belong under `docs/product/flows/`. Workflows and domain policies belong under `docs/domain/workflows/` and `docs/domain/policies/`.
