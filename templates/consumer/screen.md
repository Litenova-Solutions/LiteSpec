# Record Title

Say what page this is and what a person does on it. A reader who has read nothing else should understand the screen from this paragraph.

## Task

Explains `task`. Say the job the person does here, in one or two sentences, then draw the screen in one wireframe block. Each action in the block names a use case the screen offers, each state names a glossary term, and each refusal names a result of an offered use case.

## States

Explains `displayStates`. Say what the person sees when the page is empty, loading, failed and refused, and why each state reads that way.

## Example

One concrete use of the screen with the cast, using only the names, dates and numbers the case needs, each from the cast or a record this one cites.
