# Record Title

Say which settings this set holds and what the module runs with. A reader who has read nothing else should understand the set from this paragraph.

## Defaults

For each setting that has a default, say the default, the range it may take, who sets it and when a change takes effect. Say why the default was chosen. A setting with no default says so.

## Changes

Optional. Say who changes each setting and what the change does to the product.
