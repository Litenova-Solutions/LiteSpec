# Security Policy

## Supported Versions

| Version | Supported |
|:---|:---|
| 3.0.x | Yes |
| Older | No |

## Reporting a Vulnerability

Do not open a public issue, discussion, or pull request for an undisclosed vulnerability. Report it privately through [GitHub security advisories](https://github.com/Litenova-Solutions/LiteSpec/security/advisories/new) for this repository.

Include the affected package and version, a minimal reproduction, the impact you observed or expect, and any proposed mitigation. Do not include secrets, production payloads, or personal data.

## What to Expect

- An acknowledgement within five working days.
- An assessment of severity and affected versions.
- A fix in the supported release line, a published GitHub security advisory, and credit to the reporter unless they ask otherwise.

Coordinate public disclosure with the maintainers. The default disclosure window is 90 days from the report, or earlier once a fixed release is published.

## Scope

The scope covers the packages published from this repository: `LiteSpec.Cli` from `apps/cli/` and `LiteSpec.Analyzers` from `apps/analyzers/`. The examples under `examples/` and the site under `apps/site/` are out of scope.
